Re-wire the CRM by hand

Bit Integrations keeps its flows in its own table. Production has two, both still on Elementor. Staging moved flow 1 to WPForms and switched flow 2 off; repeat exactly that.

  1. 21Back up, repoint flow 1, switch flow 2 off

    Changing the trigger alone is not enough: flow 1’s field map still names Elementor fields, so Zoho would receive empty values. The map below is staging’s, read 10 Sep; the field IDs match form 7560 as the import delivers it.

    Novamira execute-php · production 
    global $wpdb;
$t = $wpdb->prefix . 'btcbi_flow';
update_option( 'syn_btcbi_flow_backup_launch', $wpdb->get_results( "SELECT * FROM {$t}", ARRAY_A ), false );

$d = json_decode( $wpdb->get_var( "SELECT flow_details FROM {$t} WHERE id = 1" ), true );
$d['field_map'] = array(
  array( 'formField' => '0:first', 'zohoFormField' => 'First_Name' ),
  array( 'formField' => '0:last',  'zohoFormField' => 'Last_Name' ),
  array( 'formField' => '1',       'zohoFormField' => 'Email' ),
  array( 'formField' => '3',       'zohoFormField' => 'Mobile' ),
  array( 'formField' => '2',       'zohoFormField' => 'Description' ),

$wpdb->update( $t, array( 'status' => 0 ), array( 'id' => 2 ) );

  2. 22Clear the three transients skip this and it silently never fires

    The plugin caches which trigger types it loads hooks for; editing the table does not invalidate it, so it goes on listening only for Elementor. The flow looks perfect in wp-admin and never runs. This cost a day on staging.

delete_transient( 'bit_integrations_fallback_trigger_entities' );
delete_transient( 'bit_integrations_action_hook_flows' );

What we are deliberately not doing today

  • GTM container. None has ever existed. Analytics survives launch without it.
  • Form entry storage. WPForms Lite keeps none; the notification email is the record of last resort until that is decided.
  • Rewriting titles against query phrasing. Position 5–9 on procurement queries with 300–1,150 impressions each and zero clicks is a snippet problem the rebuild does not fix by itself.
  • Deciding /our-leadership/ and the two legacy landing pages the market pages compete with.

What the numbers say about the risk

Over the three months to 7 September the site took 314 clicks from 35,645 impressions, and 79% of named-query clicks were people typing “synergi”. Non-brand search returns 20 clicks from 25,667 impressions — 0.078%.

So the entire real risk of this launch sits in one place: the homepage’s brand traffic. That is what steps 02, 10 and 16 protect.

Ticks are stored in this browser only. The written record behind every step is launch-day-state.md; the scripts are tools/transfer-export.php, tools/transfer-import.php and tools/launch-after-activation.php.
